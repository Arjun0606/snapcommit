## Long description

```
Snapcommit gives your AI tools persistent, project-aware memory across
every session and every tool.

→ Local-first: memories live in a SQLite file on YOUR machine.
→ Multi-tool: one server, works in 30+ MCP-capable clients
   (Claude Code, Cursor, Claude Desktop, Cline, Windsurf, Codex CLI,
   Gemini CLI, Zed, and more).
→ Multi-device: point Snapcommit at any cloud-synced folder
   (iCloud, Dropbox, OneDrive) — we don't build sync, your cloud does.
→ Team sharing: put the file in a shared cloud folder. That's it.
→ Captures rejections: not just what you decided, but what you
   tried and WHY it didn't work. So future sessions don't repeat
   the same mistakes. Nobody else does this.
→ AI extraction (paid): GPT-5 Nano reads your conversations and
   pulls structured memories. Content is processed in-flight and
   NEVER stored on our servers.

Try the live demo at snapcommit.com — no signup. Subscribe if it's
useful: Hobby $9, Pro $29, Studio $129.

Open source MIT on GitHub. Built solo. Real, not vapor.
```

Hey hunters! Solo dev here.

I built Snapcommit because I spent 30+ minutes every morning
re-explaining my project to Claude Code, Cursor, and ChatGPT. Then
re-explaining it again the next morning.

The problem is Reddit's #1 dev complaint about AI tools. Existing
solutions either lie about being local-first (OpenMemory ships data
to their cloud), charge $19/mo to hold your data (Supermemory), or
